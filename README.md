## Creating My AWS Account

In this step, I'm going to Sign up for a new AWS account, Verify my email Address, and create a strong root user password. 

### Understanding the root user

I learned that a root user is the account that controls everything. A strong password is important for good security

---

## Setting Up Billing and Payment

In this step, I'm going to Choose the Free account plan, Enter my Contact information, and Add a payment method.

### Why AWS requires a payment method

I learned that AWS requires a payment method so that it can charge me if I go over the bounds of the free tier.

---

## Completing Account Activation

In this step, I'm going to confirm my identity, and select a support plan.

### Identity verification and support plan

I verified my identity by uploading an ID. The Basic support plan includes 200 dollars of free credits
